### Step 1: Fix Tor Permissions & Restart It

Run these commands to fix the folder permissions so Tor stops crashing, then start it again:

```bash
# 1. Kill any broken background tor processes
pkill tor

# 2. Fix the permissions for the 'nobody' user
mkdir -p /var/lib/tor
chown -R nobody:nobody /var/lib/tor
chmod 700 /var/lib/tor

# 3. Start Tor in the background
tor --User nobody > /dev/null 2>&1 &
```

Wait 10 seconds, then verify it is running (and not crashing):
```bash

```
